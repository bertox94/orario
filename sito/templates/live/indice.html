Dati

Il seme decide quale scuola inventare: classi, docenti, lezioni e codocenze (stesso seme = stessi dati). Il file JSON è un file esportato dai dati della scuola o i dati di un test: il test li usa senza toccare quelli della scuola.

Ricerca

Il test non ha un limite di tempo: la ricerca si ferma dopo quel numero di nodi (al primo multiplo di 65.536 da quel numero in poi), sempre allo stesso punto su qualunque computer, oppure prima se trova gli orari o prova tutto; con 0 va avanti finché non la fermi col pulsante. Come nei test notturni, che si possono rifare qui con gli stessi numeri.
